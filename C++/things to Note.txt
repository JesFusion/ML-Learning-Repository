    signed variables can store both positive and negative numbers, while unsigned variables can only store positive numbers (and zero)

{
    8-Bit Types (1 Byte)
    - signed char (or int8_t) => Range: -128 to 127

    - unsigned char (or uint8_t) => Range: 0 to 255



    16-Bit Types (2 Bytes)
    - signed short (or int16_t) => Range: -32,768 to 32,767

    - unsigned short (or uint16_t) => Range: 0 to 65,535



    32-Bit Types (4 Bytes)
    - signed int / signed long (or int32_t) => Range: -2,147,483,648 to 2,147,483,647

    - unsigned int / unsigned long (or uint32_t) => Range: 0 to 4,294,967,295



    64-Bit Types (8 Bytes)
    - signed long long (or int64_t) => Range: -9,223,372,036,854,775,808 to 9,223,372,036,854,775,807

    - unsigned long long (or uint64_t) => Range: 0 to 18,446,744,073,709,551,615







    Floating-point numbers:

    - float (32-Bit / 4 Bytes)
    - Precision: ~7 decimal digits => Range: Approx. ±1.2 x 10^{-38} to ±3.4 x 10^{38}



    - double (64-Bit / 8 Bytes)
    - Precision: ~15 decimal digits  => Range: Approx. ±2.3 x 10^{-308} to ±1.7 x 10^{308}

{
    Converting Hex to Integer (Decimal):

    Hexadecimal is a Base-16 number system. It uses sixteen digits: 0-9 and A-F, where:
    A = 10
    B = 11
    C = 12
    D = 13
    E = 14
    F = 15


    To convert Hex to Decimal, you multiply each digit by a power of 16, starting from the right side (position 0).
    Example: Convert 0x23 to Decimal

    -> Look at the digits: 2 and 3.
    -> Right digit (3): 3 x 16^0 = 3 x 1 = 3
    -> Left digit (2): 2 x 16^1 = 2 x 16 = 32
    -> Add them together: 32 + 3 = 35

    Example: Convert 0x1A to Decimal

    -> Look at the digits: 1 and A (remember, A = 10).
    -> Right digit (A): 10 x 16^0 = 10 x 1 = 10
    -> Left digit (1): 1 x 16^1 = 1 x 16 = 16
    -> Add them together: 16 + 10 = 26

    
    
    
    
    
    Converting Integer (Decimal) to Hex:

    To convert a decimal number to Hex, you repeatedly divide the number by 16 and keep track of the remainders. You read the remainders backward from your last division to your first.
    Example: Convert 35 to Hex

    1. Divide 35 by 16:
        35 ÷ 16 = 2 with a remainder of 3
    2. Divide 2 by 16:
        2 ÷ 16 = 0 with a remainder of 2
    3. Read the remainders from bottom to top: 2 then 3

    -> Result: 0x23


    Example: Convert 30 to Hex

    1. Divide 30 by 16:
        30 ÷ 16 = 1 with a remainder of 14 (14 in Hex is E)
    2. Divide 1 by 16:
        1 ÷ 16 = 0 with a remainder of 1
    3. Read the remainders from bottom to top: 1 then E

    -> Result: 0x1E
