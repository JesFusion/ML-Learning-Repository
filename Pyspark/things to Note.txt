    The Driver is a single point of failure. If it dies, the job dies. This is why you never run heavy logic on the driver: it's a coordinator, not a workhorse.

    If Spark already has a function for it in pyspark.sql.functions — use it. Native Spark functions execute entirely inside the JVM. Zero Python subprocess. Zero serialization tax.
